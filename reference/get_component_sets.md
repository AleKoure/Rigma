# GET component set

Get metadata on a component_set by key. To publish components join a
Figma team and subscribe for professional account.

## Usage

``` r
get_component_sets(key)
```

## Arguments

- key:

  string. The unique identifier of the component.

## Value

S3 object of class `rigma_get_component_set`.

## Examples

``` r
if (FALSE) { # \dontrun{
component_key <- "my_key"
get_component_sets(component_key)
} # }
```
