# GET component

Get metadata on a component by key. To publish components join a Figma
team and subscribe for professional account.

## Usage

``` r
get_component(key)
```

## Arguments

- key:

  string. The unique identifier of the component.

## Value

S3 object of class `rigma_get_component`.

## Examples

``` r
if (FALSE) { # \dontrun{
component_key <- "my_key"
get_component(component_key)
} # }
```
